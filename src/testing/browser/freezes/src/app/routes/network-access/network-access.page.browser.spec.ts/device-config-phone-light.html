          Network access

          The devices and nodes on the platform’s private network, newest first.

          Connect this machine

          Run this with the qits CLI. It registers this machine as a device of yours and runs the network-access companion container, so it needs Docker.

          qits network-access up

          For a phone, or a laptop without the CLI, use Add device below: it makes the device’s keys in this browser and shows its WireGuard config once. A device row’s Download WireGuard config gives its wg-quick file without the key; put your own private key in place of <PRIVATE_KEY>.

          Browsers

          Once qits network-access up is running on this machine, set this URL as the automatic proxy configuration URL in your system’s or browser’s proxy settings. Public apps keep working while the companion is stopped.

          http://127.0.0.1:47813/proxy.pac
