Interrupt the agent

  1. Sends ESC to its harness: the turn in flight stops, the agent stays running.

Stop the agent

  1. Stops its harness; nothing starts it again until a person restarts or prompts it.
  2. Its workspace and container stay as they are.

Restart the agent

  1. A running harness is stopped and started again on its session.
  2. A yielded or stopped agent runs again once its workspace has room.

Discard the agent

  1. Removes the agent, its worktrees, its credential and its prompt draft.
  2. Refused while its worktrees hold work that never reached the git host.
